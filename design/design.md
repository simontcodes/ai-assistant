# Design System

The app should feel minimalist, calm, smart, and personal.

## Style

- Android-first mobile UI
- Light theme
- Warm off-white background
- Rounded cards
- Soft shadows
- Subtle borders
- Clean readable typography
- Minimal visual noise

## Assistant Character

The assistant character is the main visual identity of the app.

It should:
- appear near the top of the Assistant screen
- have room for future animation
- support visual states: idle, listening, thinking, suggesting, success, warning
- feel helpful and calm, not childish

## UX Principle

Most work happens behind the scenes.

The UI should not expose complex scheduling logic unless needed.
The assistant should explain decisions briefly and clearly.
