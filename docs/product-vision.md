# Product Vision

## Problem

The user often has usable gaps during the day but does not notice them in real time because planning takes cognitive effort during a busy day.

Examples:
- A dead hour at work could be used for a small personal task.
- A short evening gap could be used to pay a bill.
- A larger free window could be used for exercise, chores, or a personal project.
- Some tasks require a location, so they should not be suggested if travel time makes them unrealistic.

## Goal

Build an Android app where the main interface is a character-based AI assistant. The assistant should help the user decide what to do next by checking:

- Calendar availability
- Pending tasks
- Estimated task duration
- Best time of day for the task
- User location
- Required task location
- Travel time feasibility
- Energy level
- Priority and due dates

## Product Shape

This is not a traditional planner app.

The app should feel like talking to a personal assistant character that quietly understands the user's day and recommends realistic actions.

## Core Behavior

1. User chats with assistant.
2. Assistant extracts or updates task information.
3. App checks calendar gaps.
4. App checks task constraints.
5. App recommends a realistic task.
6. User can accept, dismiss, complete, or edit the suggestion.

## MVP Success Criteria

The MVP is successful when the user can:

- Add tasks naturally through chat.
- Connect or import calendar events.
- See realistic suggestions for free gaps.
- Avoid bad suggestions that ignore travel time or location.
- Use the assistant as the primary app interface.
